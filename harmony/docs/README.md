# ProxyPin 鸿蒙（HarmonyOS 6.1.1）迁移文档

> 状态：待审阅
> 日期：2026-08-17
> 基线版本：proxypin 1.3.1+36（main 分支）

## 目标

将 ProxyPin 迁移至 HarmonyOS 6.1.1（HarmonyOS NEXT 系，API 20），采用**本地代理服务模式**：
鸿蒙 App 内运行纯 Dart 代理内核，同一局域网的其他设备（iPhone / Android / PC）将 HTTP/SOCKS5 代理指向鸿蒙设备，实现抓包调试。

明确排除：鸿蒙本机 VPN 抓包（受限权限，另行评估）。

## 核心结论（摘要）

1. 代理内核（`lib/network/`）与 VPN 在现有架构中已解耦，服务模式"代码上已存在"：
   - `lib/network/channel/network.dart:85` 已绑定 `InternetAddress.anyIPv4`（0.0.0.0），局域网可直接连入；
   - `lib/ui/mobile/mobile.dart:127-129` App 启动即无条件启动 `ProxyServer`，VPN 为独立开关；
   - `lib/network/handle/http_proxy_handle.dart:32` 内置 `http://proxy.pin/ssl` 证书下载端点。
2. 一期（裁剪 + 平台分支 + 插件替换）无技术攻关项，可快速落地。
3. 最大平台风险为**后台保活**：无 VPN 权限即无合法常驻路径，产品定位应为"前台调试工具"。
4. 需在评审中确认的决策点见 [07-风险登记册.md](07-风险登记册.md)。
