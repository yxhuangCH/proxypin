# 01 - 可行性分析

## 1. 项目技术栈盘点

| 层 | 现状 | 鸿蒙可移植性 |
|---|---|---|
| UI 层 | Flutter，mobile + desktop 两套 UI；desktop 依赖 `window_manager`、`screen_retriever`、`desktop_multi_window`、`tray_manager` | mobile 部分可复用；desktop 部分整体裁剪 |
| 代理内核 | `lib/network/`：纯 Dart 实现的 HTTP/SOCKS5 代理服务器、TLS 中间人（`pointycastle` 纯 Dart）、拦截器链、脚本引擎 | 完全可复用，为最大利好 |
| 抓包层 | `android/` 下 30+ Kotlin 文件：`VpnService` 读 tun 设备、TCP/UDP 会话重建、socket protect | 不可用；VPN 路线需 ArkTS 全部重写且受权限限制 |
| 平台胶水 | `lib/native/`（vpn/pip/installed_apps/process_info/app_lifecycle）MethodChannel | 鸿蒙版按需裁剪或 ArkTS 重写 |
| 插件层 | 约 20 个三方插件 | 详见 [04-插件适配清单.md](04-插件适配清单.md) |

代码中存在 114 处 `Platform.isAndroid/isIOS/isWindows/...` 判断（51 个文件），迁移需统一补 ohos 分支，属机械劳动，方案见 [05-平台分支改造方案.md](05-平台分支改造方案.md)。

## 2. Flutter 引擎层

官方 Flutter 不支持鸿蒙，必须使用 OpenHarmony-SIG 的 Flutter 分支（gitee: openharmony-sig/flutter_flutter）：

- 可用分支：3.7.12-ohos / 3.22-ohos / 3.27-ohos，均适配 HarmonyOS NEXT（API 12+），可运行于 HarmonyOS 6（API 20）。
- 本项目 `pubspec.yaml` 要求 Dart SDK `>=3.0.2 <4.0.0`，3.22/3.27-ohos 满足。
- `dart:io` 的 Socket/ServerSocket、`dart:ffi` 在 ohos 引擎可用 → 纯 Dart 代理内核可直接运行，原生库路线未被封死。
- 注意：引擎为社区 fork，版本节奏落后官方；建议锁定 3.27-ohos。

## 3. 三条候选路线对比

| 路线 | 说明 | 可行性 | 主要障碍 |
|---|---|---|---|
| A. 完整 VPN 抓包 | ArkTS 重写 VpnExtensionAbility 抓包栈，抓鸿蒙本机其他 App 流量 | 技术可行，权限门槛高（详见 [08](08-VPN抓包路线专项评估.md)） | `ohos.permission.MANAGE_VPN` 为 system_basic 受限权限，**API 12 起 ACL 开放可申请**，但实践上通常需企业资质、周期不可控；Kotlin 抓包栈需全部重写；CA 无法程序化安装 |
| B. 本地代理服务模式 | 鸿蒙机跑纯 Dart 代理内核，局域网其他设备指向它抓包 | 可行（本方案） | 后台保活受限；无应用级过滤 |
| C. 远程抓包客户端 | 鸿蒙端仅作查看/控制端，抓包在 PC 执行 | 可行 | 功能价值有限，可作为 B 的附带能力 |

## 4. 选型结论

选择路线 B（本地代理服务模式），理由：

1. 内核零改动成立，现有代码已具备服务模式的全部基础设施（anyIPv4 绑定、证书下载端点、二维码互联）；
2. 无需任何受限权限，可正常上架；
3. 一期无技术攻关项，风险集中在产品设计层面（后台保活、安全控制）；
4. 路线 A 的 VPN 抓包经官方文档复核（见 [08](08-VPN抓包路线专项评估.md)）：技术链路完整且与路线 B 共用 Dart 内核，权限自 API 12 起可通过 ACL 申请。建议**与一期并行启动 ACL 申请与最小 PoC 预研**，获批后再升级为主线。

## 5. 代码证据（服务模式"已存在"）

- `lib/network/channel/network.dart:85`：`ServerSocket.bind(InternetAddress.anyIPv4, port)`，监听全部网卡；
- `lib/ui/mobile/mobile.dart:127-129`：`proxyServer.start()` 无条件执行，与 VPN 解耦；
- `lib/ui/mobile/mobile.dart:464-476`：VPN 为独立开关（`Vpn.startVpn`），移除不影响代理服务；
- `lib/network/handle/http_proxy_handle.dart:32`：内置 `http://proxy.pin/ssl`、`http://127.0.0.1:{port}/ssl` 证书下载端点；
- `lib/network/bin/configuration.dart:41`：`enableSocks5 = true`，SOCKS5 默认开启；
- `lib/ui/mobile/widgets/remote_device.dart`：二维码互联、`proxypin://connect?host=...` 协议、"我的二维码"展示本机 IP:端口，均已实现。
