# 05 - 平台分支改造方案

## 1. 现状

全库存在 114 处 `Platform.isAndroid / isIOS / isWindows / isMacOS / isLinux` 判断，分布 51 个文件。ohos Flutter 引擎中 `Platform.operatingSystem` 返回 `"ohos"`，所有现有判断在鸿蒙上均为 false —— 当前代码若直接编译运行，大量分支会走错路径（例如 `Platforms.isMobile()` 返回 false 导致启用桌面逻辑）。

## 2. 改造原则

1. **收敛入口**：所有平台判断统一走 `lib/utils/platform.dart` 的 `Platforms` 工具类，业务代码禁止直接出现 `Platform.isXxx`；
2. **语义化判断**：新增语义级 API 替代裸平台判断，降低 114 处逐一理解的成本；
3. **鸿蒙归类默认跟随 mobile**：`isMobile()` 应包含 ohos；桌面判断不受影响。

## 3. `Platforms` 工具类设计

```dart
class Platforms {
  static bool isOhos() => Platform.operatingSystem == 'ohos';

  static bool isMobile() =>
      Platform.isAndroid || Platform.isIOS || isOhos();

  static bool isDesktop() =>
      Platform.isWindows || Platform.isMacOS || Platform.isLinux;

  // 语义级 API（本次新增）
  static bool supportVpn() => Platform.isAndroid || Platform.isIOS; // ohos 不支持
  static bool supportSystemProxy() => isDesktop();
  static bool supportMultiWindow() => Platform.isWindows || Platform.isMacOS;
  static bool supportAppFilter() => Platform.isAndroid; // 应用级过滤仅 Android VPN
}
```

## 4. 改造步骤

1. 全库 grep `Platform\.is(Android|IOS|Windows|MacOS|Linux)`，逐文件替换为 `Platforms` 语义化调用；
2. 重点核对以下高风险文件（判断逻辑与抓包/代理/证书强相关）：
   - `lib/main.dart`
   - `lib/ui/launch/launch.dart`
   - `lib/ui/mobile/mobile.dart`
   - `lib/network/util/system_proxy.dart`（7 处）
   - `lib/network/util/process_info.dart`（7 处）
   - `lib/ui/mobile/setting/ssl.dart`（10 处，证书安装流程）
   - `lib/ui/component/device.dart`、`lib/network/util/file_read.dart`
3. 每处替换时按语义归类：属于"移动端通用"的走 `isMobile()`；属于"VPN 专属"的走 `supportVpn()`，ohos 自动走降级分支；
4. 完成后 `flutter analyze` + 在 ohos 真机走一遍主流程冒烟。

## 5. 易错点

- `Platform.isIOS` 的若干分支是 iOS 特有行为（如 `remote_device.dart` 的 ipProxy），不能用 `isMobile()` 笼统替换；
- `system_proxy.dart` 在 ohos 上应整体短路（`supportSystemProxy()` 为 false）；
- `process_info.dart` 桌面端通过原生方法取进程信息，ohos 走"未知进程"降级即可；
- 证书安装页（`ssl.dart`）在 ohos 本机无意义（服务端 CA 无需装到鸿蒙系统），但"导出 CA 文件 + 引导被调试设备安装"功能需保留。

## 6. 验收

- [ ] `grep -r "Platform\.is" lib/` 仅存在于 `platform.dart` 内部；
- [ ] ohos 真机上 `Platforms.isMobile() == true`、`supportVpn() == false`；
- [ ] 主流程（启动代理、抓包、历史、重写、证书导出）无分支走错导致的异常。
