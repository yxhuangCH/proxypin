# 03 - 实施计划

## 分期总览

| 期 | 目标 | 关键结果 |
|---|---|---|
| 一期 | 跑通"前台代理服务"最小闭环 | 鸿蒙真机上启动代理，PC 连入抓 HTTP/HTTPS 包，UI 可用 |
| 二期 | 体验与合规补齐 | 扫码互联、后台保活方案、局域网访问控制 |
| 三期 | 原生能力补齐 | QuickJS / zstd / brotli 鸿蒙原生库，脚本与全编码支持 |

## 一期：最小可用闭环

| # | 任务 | 涉及位置 | 验收标准 |
|---|---|---|---|
| 1.1 | 搭建 ohos Flutter 环境：安装 3.27-ohos 引擎与 DevEco Studio，配置签名证书 | 开发机环境 | `flutter doctor` 通过；空工程可跑上真机 |
| 1.2 | 生成 ohos 平台目录并接入主工程 | 新增 `ohos/` | App 在鸿蒙真机启动不白屏 |
| 1.3 | 裁剪桌面代码与桌面专属依赖 | `lib/ui/desktop/`、pubspec（window_manager / screen_retriever / desktop_multi_window / tray_manager / win32audio / code_forge 视情况） | `lib/ui/desktop/` 不参与鸿蒙编译 |
| 1.4 | 平台分支改造：`Platform.isXxx` 收敛至 `Platforms` 工具类并补 ohos 分支 | 51 个文件 114 处，见 [05](05-平台分支改造方案.md) | `flutter analyze` 通过；移动端路径在 ohos 生效 |
| 1.5 | 插件替换为 ohos 适配版 | pubspec，见 [04](04-插件适配清单.md) | 存储、路径、设备信息、分享、权限均可用 |
| 1.6 | 启动开关语义改造：VPN -> 纯代理服务 | `lib/ui/mobile/mobile.dart:464-476`、`SocketLaunch`；隔离 `lib/native/vpn.dart` 调用 | 首页开关直接控制 ProxyServer 启停 |
| 1.7 | 隐藏 VPN/系统代理/应用过滤相关 UI 入口 | `lib/ui/launch/launch.dart`、`lib/ui/mobile/setting/`、`lib/ui/mobile/menu/` | 设置页无失效入口 |
| 1.8 | 降级路径验证：brotli/zstd 解码异常兜底、脚本引擎懒加载不初始化 | `lib/network/util/compress.dart`、`lib/network/components/js/script_engine.dart` | 抓 br/zstd 接口不崩（乱码可接受）；无脚本时无原生依赖 |
| 1.9 | 权限声明与网络配置 | `ohos/module.json5`：INTERNET、GET_WIFI_INFO | 真机可绑定端口并对外服务 |
| 1.10 | 端到端联调 | - | PC 设代理 -> 装证书 -> 抓到 HTTPS 包；历史记录、重写规则生效 |

| # | 任务 | 说明 |

## 三期：原生能力补齐

| # | 任务 | 说明 |
|---|---|---|
| 3.1 | QuickJS 鸿蒙移植 | OH NDK 编译 QuickJS，参照 `flutter_js` 结构写 ohos 插件壳；恢复脚本功能 |

## 工程协作约定（建议）

- 鸿蒙改造在独立分支进行，保持 main 对现有五平台可构建；
- 所有平台分支判断收敛到 `lib/utils/platform.dart` 的 `Platforms` 类，禁止新增散落的 `Platform.isXxx`；
- `ohos/` 目录与 `harmony/` 文档目录随主仓库管理。
